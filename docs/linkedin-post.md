# LinkedIn post (task M1-17)

**This file deliberately contains no post text.** Rule 01 of Agentika 2.0: the LinkedIn and X posts must be written by you. AI-written posts lead to disqualification; only grammar-checking tools are allowed. Write it together, in your own words, in English.

## What the handbook asks for

- **One teammate publishes** the post in English. **The other reshares** it.
- Use this structure, in your own words:
  1. The project name and the problem it solves.
  2. What you built, and each person's contribution.
  3. How you used Alternate Clouds, and what you learned.
  4. A screenshot or the demo, the project link, and the hashtags.
- Hashtags (copy these exactly):
  - LinkedIn: `#AgentikaAIHackathon #AIAutomation #AIHackathon #BuildInPublic`
  - X (optional): `#AgentikaAIHackathon #AIAutomation`
