The solution

A checkpoint between the agent and its tools.

✓ allowed

Safe calls run at once

Reading email and looking up invoices never wait. The agent stays fast.

◼ held

Risky calls wait for a person

The reviewer sees the task, the hidden sentence and the call, then decides.

+ rule saved

Decisions become rules

“Always allow” and “Always block” mean fewer reviews over time.

Fail-safe: if nobody decides within 2 minutes, a held call is blocked, never allowed.

03 / 08

Instead of building another agent, we built the guard every agent needs. It sits at the tool boundary, where the damage happens, so even a fully fooled model cannot act without passing the check.
